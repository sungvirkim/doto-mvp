# 도토 · 버추얼 제작 의뢰

Node.js 24 이상에서 `npm start`를 실행한 뒤 http://127.0.0.1:4173/studio 에서 이용할 수 있습니다. 별도 패키지 설치가 필요 없습니다. `npm test`는 임시 DB를 만들어 두 사용자 사이의 의뢰 흐름을 확인합니다.

- **작가**는 작가 작업실에서 작업 이미지와 설명을 올리고 기본가, 선택 옵션, 추가금, 예상 작업 일수, 착수 가능일을 정해 상품을 발행합니다. 상품 링크로 직접 받는 문의와 도토 추천 노출을 각각 설정할 수 있습니다.
- **의뢰인**은 원하는 작업을 적거나 예시 문장을 고쳐 상담을 시작합니다. 방송용 캐릭터는 원화·참고 이미지(최대 3장), 제작 방식, 사용 프로그램과 표정 옵션을 정리한 뒤 예산·날짜에 맞는 작가를 비교합니다. 표정 추가 금액은 작가가 올린 가격표에서 계산합니다. 원하는 작가들에게 의뢰서를 보내고, 추가 질문에 답하거나 제안받은 견적을 확정할 수 있습니다.
- 로컬에서는 일반 창과 시크릿 창을 각각 작가와 의뢰인으로 사용합니다. 두 창은 별도 브라우저 세션입니다. 저장된 상품과 의뢰는 `.doto-local/`에 남습니다. 체험용 가상 작가에게 보낸 요청은 같은 세션에서 양쪽 화면을 연습할 수 있습니다.
- 호스팅에서는 방문자의 로그인 식별자와 전용 R2 저장소를 사용합니다. 담당 작가는 자신에게 온 의뢰와 해당 견적만 열람할 수 있습니다.
- Gemini를 사용하려면 실행 환경의 서버 비밀값으로 `GEMINI_API_KEY`를 설정합니다. AI 초안 버튼에서 전송에 동의한 자료만 Google로 전달됩니다. 무료 API는 공개 가능한 테스트 자료에 사용하세요. 모델이 초안을 제안하고 금액은 작가가 입력한 가격표로 계산합니다.

`npm run build`로 사이트 배포용 Worker를 `dist/server/index.js`에 생성합니다. 기존 V3 소개 페이지는 `/`, 파일럿은 `/studio`입니다.
